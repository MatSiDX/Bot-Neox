Seguridad real del proyecto

Disenado para administrar sin perder el control

La portada refleja las capas que ya existen en Bot-Neox: autenticacion por Discord, sesiones firmadas, permisos por servidor, auditoria, respaldos y variables sensibles en `.env`.

  • Inicio de sesion mediante Discord OAuth y sesiones protegidas.
  • Control de acceso por servidor, modulo y rol.
  • Validaciones administrativas adicionales para areas sensibles.
  • Persistencia principal en SQLite con compatibilidad controlada con JSON heredado.
  • Registro de eventos y acciones administrativas.
  • Backups de base de datos y configuracion operativa.
  • Variables sensibles administradas mediante `.env`.

FAQ

Preguntas frecuentes

Que es AvalonBot?

Es una plataforma formada por el bot de Discord y un dashboard web para administrar economia, eventos, tickets, auditoria, permisos y datos de Albion.

Necesito instalar algo para utilizar el dashboard?

No. El acceso se realiza desde el navegador al dashboard que ejecuta Bot-Neox, manteniendo el bot y la interfaz dentro del mismo proyecto.

Como se inicia sesion?

El acceso usa Discord OAuth. La sesion queda asociada al usuario autenticado y a los servidores donde tiene permisos validos.

Puedo administrar varios servidores?

Si, siempre que el bot este conectado a esos servidores y tu cuenta tenga acceso administrativo o permisos de modulo suficientes.

Todos los usuarios pueden acceder a todos los modulos?

No. El dashboard filtra vistas y acciones por servidor, rol y modulo, y el panel administrativo puede requerir validacion adicional.

El dashboard reemplaza los comandos de Discord?

No. La idea es complementar los comandos del bot con una vista web para operar, revisar y auditar procesos complejos.

Donde se guardan los datos?

La persistencia principal esta en SQLite, con compatibilidad controlada para algunos JSON heredados que siguen siendo parte del runtime.

Puedo exportar registros?

Si. El dashboard ya contempla exportaciones para modulos como economia y plantillas, segun el acceso del usuario.

El sistema incluye tickets y transcripciones?

Si. El proyecto maneja paneles de tickets, estados, media protegida y transcripciones consultables desde el dashboard.

Esta disenado unicamente para Albion Online?

La integracion visible y varios modulos estan orientados a Albion Online, pero el esquema operativo tambien sirve para comunidades de Discord que requieren orden y trazabilidad.
